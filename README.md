# LeadGenSI

Super Intelligence for B2B Growth.

Our mission is to give every B2B seller the leverage of a full sales team—without the complexity. Automate repetitive lead-generation work, make advanced intelligence useful, and make powerful workflows simple to use.

Product values: purposeful automation, useful intelligence, effortless usability and evidence-led trust.

The product overview highlights account and prospect targeting, automated account research, campaign preparation with outreach approval, and warm-intro opportunities from customer-provided relationship data—all through a simple, plain-language workflow.

This repository contains the standalone public product website, not the authenticated application. Product previews are explicitly illustrative; managed provider access remains subject to written application-specific approval.

The site uses no external resources or analytics scripts. `index.html` has no build step and can be hosted as static HTML. An inline-script content-security-policy hash must be regenerated if JavaScript changes.
